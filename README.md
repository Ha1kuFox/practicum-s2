# YndxS2: Финальный проект

> Я изучил как проектировать приложения так что не могу себе позволить сразу начать накидывать не продумав все детали

Название: Счетчик калорий
Тип проекта: CLI (Java Core only)

## Функционал

- Консольный интерфейс для управления программой (цикл меню с командами 1-4)
- Хранение данных о количестве пройденных шагов за 12 месяцев (не персистентно, File IO пока не проходили, все данные в оперативке). Запрашивается номер месяца (1-12) и день (1-30), статистика считается по месяцу
- Ввод цели на день (цель одна на всё приложение). Учитывается при расчёте "лучшей серии": день засчитывается в серию, если шагов `>=` цели
- Ввод выполненного числа шагов за день (запрос месяца и дня, запись)
- Вывод статистики за выбранный месяц:
  - количество шагов по дням
  - общее число шагов, максимум за день, среднее (за 30 дней)
  - пройденная дистанция в км и сожжённые килокалории
  - лучшая серия подряд идущих "целевых" дней

## Проверки по ТЗ

- Номер месяца: должен быть от 1 до 12 (`Неверный номер месяца`).
- Номер дня: должен быть от 1 до 30 (`Неверный номер дня`).
- Количество шагов: не может быть отрицательным (`Указано неверное количество шагов`).
- Цель по шагам: должна быть больше нуля (`Цель должна быть больше нуля`).
- Номер команды меню: 1-4, иначе `Нет такой команды`.

## Классы и ответственность

- `Main` — точка входа: вывод меню, чтение команд, вызов сервиса `StepTracker`.
- `StepTracker` — основной сервис: ввод шагов за день, изменение цели, вывод статистики, валидация входных данных. Хранит массив из 12 `MonthData`.
- `MonthData` — данные одного месяца (массив из 30 дней) и преобразование шагов в читаемую статистику (дистанция, калории, серия).
